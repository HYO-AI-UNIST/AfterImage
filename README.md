# MindMiner

기억으로 길을 찾는 6인 온라인 보드게임입니다. 브라우저에서 방을 만들고 초대 링크로 참가하거나, 자동 탐험가 5명과 혼자 데모를 체험할 수 있습니다.

## 실행

Node.js 24 이상과 npm을 사용합니다.

```bash
npm ci
npm run db:local
npm run dev -- --hostname 127.0.0.1 --port 4173
```

`db:local`은 빌드 후 프로젝트 내부의 로컬 D1 데이터베이스에 아직 적용하지 않은 마이그레이션만 적용합니다. 개발 서버는 `http://127.0.0.1:4173`에서 실행합니다. 원격 서버에서는 SSH/VS Code의 포트 전달로 접근할 수 있습니다. 다른 기기의 참가자도 접근할 수 있는 공유 호스트가 있어야 온라인 방을 함께 이용할 수 있습니다.

Sites 배포 설정은 `.openai/hosting.json`에 있습니다. 사이트 공개 범위는 게임방 코드와 별개입니다. 비공개 사이트는 호스팅의 접근 권한을 가진 사람만 이용할 수 있습니다. 로컬 데이터와 배포된 데이터는 분리됩니다.

## 플레이

1. 이름을 입력해 방을 만들고 초대 링크를 공유합니다. 6명이 모이면 방장이 시작합니다.
2. 각자 선분을 눌러 지뢰를 배치합니다. 밑변에는 설치할 수 없고, 정상까지 안전한 길 하나 이상을 남겨야 합니다. 랜덤 배치와 전체 지우기도 가능합니다.
3. 모두 준비하면 판을 왼쪽으로 전달합니다. 자기 차례에 밑변의 점을 선택하고, 연결된 점을 눌러 어느 방향으로든 이동합니다.
4. 지뢰가 터지면 말만 사라지고 다음 사람 차례가 됩니다. 지뢰는 남습니다. 전원이 실패하면 판을 다시 왼쪽으로 넘기며, 자기 판이 돌아오는 단계는 모두 함께 건너뜁니다.
5. 힌트는 자신의 차례에 코인 하나를 쓰고 선분 하나의 지뢰 유무를 확인합니다. 확인창을 닫으면 답변이 사라집니다. 같은 곳에 다시 질문해도 코인을 사용합니다.
6. 먼저 정상에 도달한 사람만 `1 + 남은 코인`점을 얻습니다. 7라운드 후 최고 점수는 공동 우승이 가능합니다.

첫 라운드 시작자는 무작위입니다. 다음 라운드는 직전 승자의 왼쪽 사람부터 시작합니다. 좌석은 화면의 1번부터 시계방향이며, 왼쪽 이웃은 다음 좌석입니다. 코인은 라운드당 3개이고 로테이션에서는 보충되지 않습니다.

이동과 폭발은 모두에게 잠깐 보이지만 판에 흔적이 남지 않습니다. 힌트 질문과 답변은 질문자에게만 표시됩니다. 배치가 끝나 탐색이 시작되면 제작자도 배치도를 다시 열 수 없습니다.

## 데모와 재접속

데모는 첫 라운드를 사용자가 시작하며 나머지 다섯 명이 자동으로 이동합니다. 데모 탐험가는 지뢰 배치를 읽지 않고 격자의 연결만 보고 이동합니다. 실제 상대방의 추리 능력을 모사하는 AI는 아닙니다. 데모 상태는 브라우저 메모리에만 있고 새로고침하면 초기화됩니다.

온라인 방은 서버에 보관됩니다. 같은 브라우저에서 새로고침하거나 홈의 이전 방 연결을 사용하면 자신의 자리를 복원합니다. 브라우저에는 방 코드와 본인의 재접속 토큰만 저장하며, 이동·힌트 기록은 저장하지 않습니다. 토큰을 지우면 기존 자리를 복구할 수 없습니다. 방은 마지막 활동 후 24시간에 만료됩니다.

초기 버전은 잠수 플레이어 자동 퇴장이나 차례 제한시간을 두지 않습니다. 참가자가 연결을 끊어도 자리는 유지되므로, 해당 플레이어가 다시 접속해야 그 차례를 진행할 수 있습니다. 한 기기에서 여러 사람을 시험할 때는 서로 독립적인 브라우저 프로필을 사용하세요.

## 검증

```bash
npm test
npm run typecheck
npm run build
```

게임 규칙 테스트는 안전 경로, 양방향 이동, 자기 판 제외, 힌트와 기록 비공개, 7라운드와 동점을 검증합니다. 서비스 테스트는 인증, 동시 참가, 중복 힌트 차감 방지, 동시 폭발 처리, 오래된 요청과 만료를 검증합니다.

서버가 실행된 상태에서 실제 브라우저 검사도 재현할 수 있습니다.

```bash
npx playwright install chromium
npm run test:browser
```

기본 주소는 `http://127.0.0.1:4173`입니다. 다른 주소는 `MINDMINER_URL` 환경변수로 지정합니다. 여섯 개의 독립 브라우저 세션으로 참가·배치·개인 힌트·새로고침·공개 폭발·점수·다음 라운드를 확인하고, 모바일 데모도 검사합니다. 화면 캡처는 `outputs/qa/`에 저장합니다.

## 소스 구성

- `app/page.tsx`, `components/mindminer/`: 방과 게임 화면, SVG 보드
- `lib/game.ts`: 플랫폼과 분리된 게임 규칙 및 공개 정보 생성
- `lib/room-service.ts`, `app/api/rooms/`: 참가 인증과 온라인 상태 처리
- `lib/demo.ts`: 브라우저 내부의 데모 진행
- `db/schema.ts`, `drizzle/`: D1 스키마와 마이그레이션

온라인 지뢰판은 서버에만 저장하고 허용된 정보만 각 참가자에게 전달합니다. 상태 변경에는 버전 비교를 사용해 중복 요청이나 동시 요청으로 코인과 차례가 두 번 처리되지 않게 합니다. 모든 게임 API 응답은 캐시하지 않습니다.

글꼴은 Pretendard 1.3.9를 자체 제공하며 라이선스는 `public/fonts/OFL.txt`에 포함되어 있습니다.
