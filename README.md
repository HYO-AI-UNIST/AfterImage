# 잔상

기억으로 길을 찾는 2~8인 온라인 보드게임입니다. 대기·관전 인원을 포함해 방 하나에 최대 32명이 들어올 수 있습니다. 브라우저에서 방을 만들고 초대 링크로 참가하거나, 봇 5명과 혼자 데모를 체험할 수 있습니다.

## 실행

Node.js 24 이상과 npm을 사용합니다.

```bash
npm ci
npm run db:local
npm run dev -- --hostname 127.0.0.1 --port 4173
```

`db:local`은 빌드 후 프로젝트 내부의 로컬 D1 데이터베이스에 아직 적용하지 않은 마이그레이션만 적용합니다. 개발 서버는 `http://127.0.0.1:4173`에서 실행합니다. 원격 서버에서는 SSH/VS Code의 포트 전달로 접근할 수 있습니다. 다른 기기의 참가자도 접근할 수 있는 공유 호스트가 있어야 온라인 방을 함께 이용할 수 있습니다.

Sites 배포 설정은 `.openai/hosting.json`에 있습니다. 사이트 공개 범위는 게임방 코드와 별개입니다. 비공개 사이트는 호스팅의 접근 권한을 가진 사람만 이용할 수 있습니다. 로컬 데이터와 배포된 데이터는 분리됩니다.

## 이 서버에서 실행하기 — 7777 포트

이 서버에는 `hserver` 계정의 systemd 사용자 서비스 `mindminer.service`를 등록했습니다. 빌드된 앱을 로컬 Workers 런타임에서 실행하며, 개발 화면의 실시간 소스 갱신 기능은 사용하지 않습니다.

- 서버 내부: `http://127.0.0.1:7777`
- 서버의 LAN 주소: `http://192.168.0.2:7777` (같은 네트워크에서 접근)
- 수신 주소: `0.0.0.0:7777`
- 데이터: 프로젝트의 `.wrangler/state/`에 저장되며 서비스를 재시작해도 유지됩니다.
- Node.js: `.sites-runtime/node/bin/node`에 독립적으로 보관한 v24.21.0을 사용합니다. `/tmp`나 VS Code 설치 경로에 의존하지 않습니다.
- 실행 유지: 로그아웃 이후에도 실행되도록 사용자 linger를 켰으며, 부팅 시 자동 시작과 오류 시 재시작을 설정했습니다.

프로젝트 디렉터리에서 다음 명령으로 관리합니다.

```bash
./scripts/server.sh status   # 실행 상태
./scripts/server.sh logs     # 최근 로그와 실시간 로그
./scripts/server.sh restart  # 서버 재시작
./scripts/server.sh stop     # 서버 중지
./scripts/server.sh start    # 서버 시작
./scripts/server.sh update   # 중지 → 빌드·DB 마이그레이션 → 시작
```

소스를 변경했다면 `update`를 사용합니다. 실행 중인 앱의 빌드 파일을 교체하지 않도록 먼저 서비스를 중지하며, 빌드가 실패하면 서비스는 중지 상태로 남습니다. 서비스 설정은 `ops/mindminer.service`이고, 사용자 서비스 폴더에서 이 파일을 링크합니다. 설정을 수정한 뒤에는 `systemctl --user daemon-reload`와 `./scripts/server.sh restart`를 실행합니다.

이 주소의 게임방은 기존 Sites 주소의 게임방과 별개입니다. 모든 참가자가 동일한 서버 주소로 접속해야 합니다. 인터넷 도메인, HTTPS, 공유기 포트 전달은 아직 설정하지 않았습니다.

## 플레이

1. 이름을 입력해 방을 만들고 초대 링크를 공유합니다. 방장은 대기실에서 인원 2~8명, 라운드당 힌트 0~10개, 총 1~20라운드, 변 3~6등분을 정할 수 있습니다. 기본값은 6명·3개·7라운드·4등분입니다. 선택하는 즉시 자동으로 반영되고 참가석이 모두 차면 시작합니다. 게임 중에는 설정과 참가석을 바꿀 수 없습니다.
2. 각자 선분을 눌러 지뢰를 배치합니다. 밑변에는 설치할 수 없고, 정상까지 안전한 길 하나 이상을 남겨야 합니다. 지뢰는 밑변을 제외한 배치 가능한 선분 수의 50%까지 설치할 수 있으며 소수점은 버립니다. 3·4·5·6등분 판에서는 각각 최대 7·13·20·28개입니다. 화면과 서버에서 모두 제한하며 랜덤 배치·데모 봇에도 같은 제한이 적용됩니다. 상한에 도달해도 지뢰 제거와 전체 지우기는 가능합니다.
3. 모두 준비하면 판을 왼쪽으로 전달합니다. 자기 차례에 밑변의 점을 선택하고, 연결된 점을 눌러 어느 방향으로든 이동합니다.
4. 지뢰가 터지면 말이 사라지고, 폭발 위치와 다음 차례 안내를 4초 동안 보여준 뒤 다음 사람에게 넘어갑니다. 기다리는 동안에는 이동과 힌트를 사용할 수 없습니다. 지뢰는 남습니다. 전원이 실패하면 판을 다시 왼쪽으로 넘기며, 자기 판이 돌아오는 단계는 모두 함께 건너뜁니다.
5. 힌트는 자신의 차례에 코인 하나를 쓰고 선분 하나의 지뢰 유무를 확인합니다. 확인창을 닫으면 답변이 사라집니다. 같은 곳에 다시 질문해도 코인을 사용합니다.
6. 먼저 정상에 도달한 사람만 `1 + 남은 코인`점을 얻습니다. 라운드 종료 화면에서 모든 판의 지뢰 배치를 공개하며, 이름을 선택하면 해당 판의 정답을 볼 수 있습니다. 관전자도 볼 수 있습니다. 다음 라운드가 시작되면 공개된 판은 사라지고 새 배치를 시작합니다. 정해진 라운드가 모두 끝나면 최고 점수가 승리하며 공동 우승이 가능합니다.

대기실에 입장하면 빈 참가석에 자동으로 앉고, 참가석이 가득 찼거나 게임이 진행 중이면 대기·관전으로 입장합니다. 방장은 참가자를 대기석으로 내리거나 빈 참가석으로 올릴 수 있습니다. 참가 인원을 줄이면 앞자리부터 정원만큼 남고 나머지는 기존 대기열 뒤로 이동합니다. 예를 들어 7명에서 4명으로 줄이면 앞의 4명은 남고 뒤의 3명이 대기석으로 내려갑니다. 인원을 늘리면 대기 순서대로 빈 참가석을 채웁니다. 방장이 직접 내린 자리는 다음 입장이나 수동 올리기까지 비어 있습니다.

대기석의 사람들은 게임이 시작되면 관전합니다. 이동·폭발과 공개 점수는 볼 수 있지만 배치도와 개인 힌트는 볼 수 없고 플레이에 개입할 수 없습니다. 방장 자신도 관전할 수 있으며 시작·다음 라운드 진행 권한은 유지됩니다. 최종 결과에서 방장이 대기실로 돌아가기를 누르면 새 게임의 인원·규칙·참가석을 다시 정할 수 있습니다.

그리드 난이도는 쉬움(3등분), 기본(4등분), 어려움(5등분), 매우 어려움(6등분)입니다. 출발점·선분·안전 경로 검사·랜덤 배치가 모두 선택한 크기에 맞춰 바뀝니다. 판이 커질수록 지뢰를 놓을 수 있는 선분과 지뢰 상한도 함께 늘어납니다.

첫 라운드 시작자는 무작위입니다. 다음 라운드는 직전 승자의 왼쪽 사람부터 시작합니다. 좌석은 화면의 1번부터 시계방향이며, 왼쪽 이웃은 다음 좌석입니다. 코인은 라운드마다 설정한 개수로 보충되며 로테이션에서는 보충되지 않습니다. 기본 힌트가 0개여도 ‘잔광의 인도’를 선택하면 추가 힌트 2개를 받습니다.

이동과 폭발은 모두에게 잠깐 보이지만 판에 흔적이 남지 않습니다. 힌트 질문과 답변은 질문자에게만 표시됩니다. 판 오른쪽 위에는 현재 탐색 중인 판의 총 지뢰 수가 모든 플레이어와 관전자에게 표시됩니다. 이 숫자는 터지거나 힌트를 사용해도 줄지 않으며 차례나 판이 바뀌면 현재 판에 맞춰 갱신됩니다. 지뢰 위치는 공개하지 않습니다. 라운드 중 배치도는 숨겨지며, ‘위험의 전이’를 가진 플레이어에게 자기 판이 돌아와 이동 여부를 선택하는 동안만 자신의 판을 다시 보여줍니다. 그 외에는 제작자도 배치도를 다시 열 수 없고, 라운드가 끝난 뒤 모든 판을 공개합니다. 이전 라운드의 이동·힌트 내역이나 배치도는 다음 라운드 화면에 남기지 않습니다.

화면 오른쪽 위에서 라이트·다크 모드를 선택합니다. 기본은 다크 모드이며, 선택은 브라우저에 저장되어 새로고침해도 유지됩니다.

## 특수 능력과 메모

매 라운드 지뢰 배치 전에 각자 특수 능력을 직접 선택하며 중복을 허용합니다. 준비 완료 전까지 바꿀 수 있습니다. 특수 능력 이름은 공개되지만 개인 메모·힌트·남은 능력 횟수는 본인에게만 전달합니다. 2인전에서는 메모가 없어 ‘타인의 기억’과 ‘기억의 각인’을 제외합니다.

| 특수 능력 | 효과 |
| --- | --- |
| 잔광의 인도 | 기본 힌트 +2개. 남은 추가 힌트도 승점에 포함됩니다. |
| 귀환의 가호 | 라운드당 가호 2개. 폭발 4초 후 사용을 선택하면 같은 차례에 밑변에서 다시 출발합니다. 한 차례에 연속 사용 가능하며 지뢰는 남습니다. |
| 기만의 장막 | 배치 중 밑변을 제외한 선분 최대 4개를 위장합니다. 안전한 길도 선택 가능하며 해당 힌트는 코인을 소비하고 ‘판독 불가’를 반환합니다. |
| 타인의 기억 | 내 차례에 라운드당 2번, 한 번에 기본 메모 수만큼 다른 사람의 작성된 슬롯을 골라 잠깐 확인합니다. 내용은 확인 전까지 숨겨지며 자동 저장되지 않습니다. |
| 위험의 전이 | 라운드당 최대 7번, 자기 판이 돌아오면 지뢰 하나를 빈 선분으로 옮길 수 있습니다. 실제 이동에 성공했을 때만 1회를 사용하며, 그대로 전달하거나 유효하지 않은 이동을 시도하면 횟수를 쓰지 않습니다. 모두 사용한 뒤에는 자기 판을 자동으로 넘기며 다음 라운드에 7회로 보충합니다. 지뢰 수·상한·안전 경로 조건을 유지합니다. 여러 명이면 순서대로 선택합니다. |
| 기억의 각인 | 기본 메모 슬롯의 두 배를 받습니다. |

메모 기본 수는 2명 0칸, 3~4명 1칸, 5~6명 2칸, 7~8명 3칸입니다. 한 슬롯은 판의 주인·선분 하나·안전/지뢰/미확인 추측을 담습니다. 내 차례에 현재 판이나 다른 판을 직접 기록·수정·삭제할 수 있고, 현재 판에 해당하는 기록은 내 화면에만 점선 표시로 나타납니다. 정답 검사나 자동 수정은 없으며 지뢰가 이동해도 이전 기록을 그대로 유지합니다. 새 라운드에는 메모가 지워지고 새 특수 능력에 맞춰 자원이 보충됩니다.

가호와 지뢰 이동의 선택 중에는 일반 행동을 잠시 멈추며 시간 제한은 없습니다. 선택자가 재접속하면 이어서 결정할 수 있습니다. 예전 방은 진행 중인 라운드를 유지하고 다음 라운드부터 특수 능력을 선택합니다.

메인 화면의 예시 재생 버튼 옆 ‘특수 능력’에서 여섯 능력의 이야기와 효과를 좌우로 넘겨 볼 수 있습니다. 오래된 광산의 길잡이 시험을 배경으로 각 능력을 설명하며, 이야기 아래에 실제 적용 규칙을 표시합니다. 화살표·키보드·모바일 스와이프를 지원합니다. 연습 모드에서도 배치 전에 특수 능력을 직접 바꿔 능력을 체험할 수 있습니다.

## 데모와 재접속

데모는 첫 라운드를 사용자가 시작하며 나머지 다섯 명이 자동으로 이동합니다. 데모 봇은 지뢰 배치를 읽지 않고 격자의 연결만 보고 이동합니다. 실제 상대방의 추리 능력을 모사하는 AI는 아닙니다. 데모 상태는 브라우저 메모리에만 있고 새로고침하면 초기화됩니다.

온라인 방은 서버에 보관됩니다. 같은 브라우저에서 새로고침하거나 홈의 이전 방 연결을 사용하면 자신의 자리를 복원합니다. 브라우저에는 방 코드와 본인의 재접속 토큰만 저장하며, 이동·힌트·훔쳐보기 답변은 저장하지 않습니다. 직접 작성한 개인 메모는 서버에 보관되어 같은 라운드에 재접속하면 복원됩니다. 토큰을 지우면 기존 자리를 복구할 수 없습니다. 방은 마지막 활동 후 24시간에 만료됩니다.

초기 버전은 잠수 플레이어 자동 퇴장이나 차례 제한시간을 두지 않습니다. 참가자가 연결을 끊어도 자리는 유지되므로, 해당 플레이어가 다시 접속해야 그 차례를 진행할 수 있습니다. 한 기기에서 여러 사람을 시험할 때는 서로 독립적인 브라우저 프로필을 사용하세요.

## 검증

```bash
npm test
npm run typecheck
npm run build
```

게임 규칙 테스트는 안전 경로, 양방향 이동, 자기 판 제외, 힌트와 기록 비공개, 7라운드와 동점을 검증합니다. 서비스 테스트는 인증, 동시 참가, 중복 힌트 차감 방지, 동시 폭발 처리, 오래된 요청과 만료를 검증합니다.

서버가 실행된 상태에서 실제 브라우저 검사도 재현할 수 있습니다.

```bash
npx playwright install chromium
npm run test:browser
# 방 설정과 테마 검증 (서버 실행 필요)
MINDMINER_URL=http://127.0.0.1:7777 node tests/browser-settings.mjs
# 자동 좌석 배분, 대기·관전, 가변 그리드 검증
MINDMINER_URL=http://127.0.0.1:7777 node tests/browser-roster.mjs
# 지뢰 상한, 차례별 총 개수, 라운드 종료 정답 공개 검증
MINDMINER_URL=http://127.0.0.1:7777 node tests/browser-mines.mjs
# 특수 능력 소개, 직접 특수 능력 선택, 메모 비공개, 가호·훔쳐보기·지뢰 이동 검증
MINDMINER_URL=http://127.0.0.1:7777 node tests/browser-roles.mjs
```

브라우저 검사의 기본 주소는 `http://127.0.0.1:7777`입니다. 다른 주소는 `MINDMINER_URL` 환경변수로 지정합니다. 여섯 개의 독립 브라우저 세션으로 참가·배치·개인 힌트·새로고침·공개 폭발·점수·다음 라운드를 확인하고, 모바일 데모도 검사합니다. 화면 캡처는 `outputs/qa/`에 저장합니다.

## 소스 구성

- `app/page.tsx`, `components/mindminer/`: 방과 게임 화면, SVG 보드
- `lib/game.ts`: 참가·대기석 관리, 플랫폼과 분리된 게임 규칙 및 공개 정보 생성
- `lib/roles.ts`: 특수 능력 설명, 힌트 보너스와 메모 슬롯 계산
- `lib/geometry.ts`: 3~6등분 삼각형 생성과 안전 경로 검사
- `lib/room-service.ts`, `app/api/rooms/`: 참가 인증과 온라인 상태 처리
- `lib/demo.ts`: 브라우저 내부의 데모 진행
- `db/schema.ts`, `drizzle/`: D1 스키마와 마이그레이션

온라인 지뢰판은 서버에만 저장하고 허용된 정보만 각 참가자에게 전달합니다. 상태 변경에는 버전 비교를 사용해 중복 요청이나 동시 요청으로 코인과 차례가 두 번 처리되지 않게 합니다. 모든 게임 API 응답은 캐시하지 않습니다.

글꼴은 Pretendard 1.3.9를 자체 제공하며 라이선스는 `public/fonts/OFL.txt`에 포함되어 있습니다.
