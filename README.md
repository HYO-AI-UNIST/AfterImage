# MindMiner · Quiet Mine

기억으로 출구를 찾는 6인 온라인 보드게임입니다. `game` 브랜치에서는 세미 레트로 컨셉을 바탕으로 실제 3D 갱도, 광부 수레, 이미지 에셋 HUD로 플레이합니다. 혼자서는 봇 5명과 즉시 탐험할 수 있습니다.

## 실행

Node.js 24 이상이 필요합니다.

```bash
npm ci
npm run game:db
npm run dev -- --hostname 127.0.0.1 --port 5173
```

브라우저에서 `http://127.0.0.1:5173/`를 엽니다. `game:db`는 **로컬 D1에만** 마이그레이션을 적용합니다. 서버가 이미 실행 중이어도 적용할 수 있습니다. 온라인 방은 같은 서버 주소에 접속한 브라우저끼리 이용하며, 배포된 데이터와 로컬 데이터는 분리됩니다.

현재 실행 환경에서 Node가 PATH에 없으면, Codex가 제공하는 Node 실행 파일을 PATH에 추가해 사용합니다. 게임 자체에는 설치된 Blender가 필요하지 않습니다. 내보낸 GLB와 PNG가 저장소에 포함되어 있습니다.

## 플레이

1. **혼자 탐험하기**로 바로 연습하거나 **친구와 플레이**에서 이름을 입력해 방을 만듭니다. 방 코드와 초대 링크로 참가할 수 있습니다.
2. 온라인 방은 6명이 모두 모이면 방장이 시작합니다. 연습에서는 다섯 봇의 배치가 자동으로 준비됩니다.
3. 선로를 눌러 지뢰를 설치·제거합니다. 출구까지 안전한 길 하나 이상을 남겨야 합니다. 밑변 선로는 항상 안전합니다. 랜덤 배치와 전체 지우기도 가능합니다.
4. 모두 준비하면 다른 사람의 갱도를 탐색합니다. 출발역 1~5 중 하나에서 시작해 인접 분기점으로 이동합니다. 옆으로 이동하거나 되돌아갈 수도 있습니다.
5. 안전한 이동은 약 650ms 재생합니다. 폭발하면 말이 사라지고 약 1.8초 뒤 다음 차례가 됩니다. 전원이 실패하면 판을 전달합니다. 자기 판은 건너뜁니다.
6. 내 차례에 힌트 코인 하나로 선로 하나의 지뢰 유무를 확인합니다. 개인 힌트를 닫으면 답은 사라집니다. 이동·폭발·힌트의 지속 기록은 없습니다.
7. 먼저 출구에 도착하면 `1 + 남은 힌트 코인`점을 얻습니다. 방장이 다음 라운드를 시작합니다. 총 7라운드 누적 점수로 승리하며 동점은 공동 우승입니다.

매 라운드 코인은 3개로 보충됩니다. 시작자는 첫 라운드에 무작위, 다음부터는 직전 승자의 왼쪽 사람입니다. 초기 규칙과 동일하게 인원·라운드·보드 크기는 고정입니다.

## 조작

| 입력 | 동작 |
|---|---|
| 마우스 클릭 / 터치 | 이미지 메뉴 선택, 선로 배치, 출발역·분기점 선택 |
| 빈 공간 드래그 | 제한된 범위에서 카메라 회전 |
| 휠 / 두 손가락 핀치 | 제한된 범위에서 확대·축소 |
| `1` ~ `5` | 내 차례에 해당 출발역에서 시작 |
| `←` / `→`, `Enter` | 이동 가능한 분기점 선택 후 이동 |
| `H` | 힌트 선택 모드 / 취소 |
| `R` | 배치 중 랜덤 배치 |
| `C` | 카메라 초기화 |
| `M` | 소리 켜기 / 끄기 |
| `Tab`, `Shift+Tab`, `Enter` | 이미지 메뉴의 키보드 탐색 |
| `Escape` | 모달 닫기 / 게임 메뉴 |

모바일은 터치와 핀치를 지원합니다. 텍스트 입력란을 누르면 네이티브 키보드가 열립니다. 첫 입력 이후 작은 환경음과 이동·힌트·폭발 효과음을 재생하며 메뉴에서 끌 수 있습니다. 온라인 게임은 메뉴를 열거나 홈으로 돌아가도 계속 진행됩니다.

## 렌더링과 UI

게임은 **단 하나의 WebGL 캔버스**에 렌더링합니다.

- Three.js의 3D 월드: 실제 철도 메시, 분기점, 광부 수레 GLB, 암벽과 목재 지지대, 갱도 조명·그림자.
- PNG 이미지 HUD: 9-slice 패널·버튼, 광부 초상화, 아이콘, 타이틀을 UI 아틀라스에서 합성한 뒤 GPU 텍스처로 렌더링합니다.
- 이름·코드·점수 등의 동적 글자는 오프스크린 캔버스에 래스터화해 같은 UI 텍스처에 합성합니다. 화면에 HTML 버튼·카드·텍스트 패널을 배치하지 않습니다.
- 이름과 초대 코드를 입력하기 위한 보이지 않는 네이티브 입력 요소 하나만 DOM에 둡니다. IME와 모바일 키보드를 위한 요소이며 시각 UI는 모두 게임 이미지입니다.
- 카메라는 프레임 시간에 따른 보간으로 홈·탐험·결과 사이를 이동하고, 이동 중 광부를 약하게 추적합니다. 드래그와 줌은 플레이 가능한 범위로 제한됩니다.
- 폭발 불꽃·충격파, 부유 먼지, 갱도등과 헤드램프, 짧은 카메라 진동을 사용합니다. 모션 축소 설정에서는 카메라 진동과 반복 움직임을 줄입니다.

WebGL 2를 지원하는 최근 Chrome, Edge, Safari가 필요합니다. 모바일에서는 렌더링 픽셀 비율과 그림자 해상도를 낮춥니다. 현재 브라우저 검증은 Chromium의 데스크톱·모바일 뷰포트에서 수행합니다. 실제 iOS/Android 하드웨어 성능 검증은 별도입니다.

## 원본 게임 에셋

| 종류 | 위치 |
|---|---|
| 편집 가능한 Blender 원본 | `assets/source/quiet-mine-kit.blend` |
| 광부 수레·목재 지지대·랜턴·상자·암벽 GLB | `public/game/models/` |
| UI PNG 아틀라스와 프레임 정보 | `public/game/ui/atlas.png`, `atlas.json` |
| 개별 PNG 버튼·초상화·아이콘·로고 | `public/game/ui/` |
| 한눈에 보는 UI 에셋 시트 | `public/game/ui/asset-sheet.png` |
| 광원·먼지·불꽃 PNG | `public/game/fx/` |
| 에셋 목록 | `public/game/manifest.json` |

모델과 UI는 이 프로젝트를 위해 직접 제작했습니다. 외부 게임의 캐릭터나 이미지 파일은 사용하지 않습니다. 컨셉의 단순한 형태와 평면 색을 유지하며 텍스처 없이 재질을 정의합니다.

```bash
npm run assets:ui  # PNG UI·이펙트·아틀라스 재생성
npm run assets:3d  # Blender로 GLB와 .blend 재생성
```

macOS의 `/Applications/Blender.app`을 자동으로 찾습니다. 다른 설치 위치에서는 `BLENDER_BIN=/path/to/blender npm run assets:3d`로 지정합니다.

## 검증

```bash
npm test
npm run typecheck
npm run build
npx playwright install chromium --only-shell
npm run test:game
```

`test:game`은 개발 서버가 실행된 상태에서 사용합니다. 다른 주소는 `MINDMINER_URL`로 지정합니다. 프로젝트 로컬 브라우저 캐시를 쓰려면 설치·실행 시 같은 `PLAYWRIGHT_BROWSERS_PATH`를 지정합니다.

브라우저 검사는 실제 캔버스 좌표를 눌러 연습, 배치, 개인 힌트, 카메라 조작, 모바일 터치, 온라인 6인 참가, 승점과 다음 라운드, 새로고침 재접속을 확인합니다. 시각 UI에 DOM 버튼이 없는지도 검사합니다. 결과 화면은 `outputs/qa/game/`에 저장됩니다. 기존 게임 규칙·방 인증 테스트 24개도 유지합니다.

## 주요 소스

- `app/page.tsx`: 캔버스와 보이지 않는 키보드 입력 호스트
- `lib/mine/world.ts`: Three.js 월드·모델·카메라·선로 선택·이펙트
- `lib/mine/hud.ts`: PNG 아틀라스 합성과 이미지 메뉴·모달
- `lib/mine/engine.ts`: 입력·상태·3D·HUD 연결과 수명 관리
- `lib/mine/session.ts`: 온라인 API·재접속·로컬 연습 상태
- `lib/mine/audio.ts`: 사용자 입력으로 시작되는 환경음·효과음
- `lib/game.ts`, `lib/contracts.ts`: 서버와 공유하는 게임 규칙과 타입
- `lib/room-service.ts`, `app/api/rooms/`: 인증·비공개 투영·동시 요청 처리
- `scripts/design/build_game_models.py`, `build_game_ui.mjs`: 재생성 가능한 에셋 제작 코드

온라인 지뢰판과 참가 인증은 서버에서 관리합니다. 본인의 배치 단계 이외에는 지뢰 배열을 클라이언트에 전달하지 않으며, 개인 힌트는 질문자에게만 반환합니다. 브라우저에는 재접속을 위한 방 코드와 토큰만 저장합니다. 온라인 방은 마지막 활동 후 24시간에 만료됩니다. 잠수 플레이어 자동 퇴장과 차례 제한시간은 아직 없습니다.
